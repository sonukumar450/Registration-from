# Registration Form Project

## About Project
This is a Registration Form web application developed using HTML, CSS, JavaScript and Spring Boot. It allows users to submit their registration details, which are stored in a MySQL database.

## Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- Maven

### Database
- MySQL

### Development Tools
- IntelliJ IDEA
- Postman
- Git & GitHub

## Features
- User Registration
- Form Validation
- REST API Integration
- Save Registration Data
- MySQL Database Connectivity

## Project Architecture

- Controller
- Service
- Repository
- Entity
- DTO

## Database Configuration

Database Name: `Registration_db`

Database: MySQL

## API Endpoint

**Save Registration**

`POST /api/registration/save`

## How to Run the Project

1. Clone or download the project.
2. Open the project in IntelliJ IDEA.
3. Configure MySQL in `application.properties`.
4. Create the database `Registration_db`.
5. Run the Spring Boot application.
6. Open the registration HTML file in your browser.
